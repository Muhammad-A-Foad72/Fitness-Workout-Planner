# RepWise — Tests & Verification

This directory records Phase 2 responsive and accessibility verification evidence for the static HTML + Tailwind prototype.

- **[Phase 2 UI Verification & Manual Test Report](phase-2-testing.md)** — scope, observed Lighthouse results, responsive screenshot review, Role C source review, open checks, limitations and discussion reminders.
- **[Evidence images](evidence/)** — local screenshots provided during the review. See the evidence table inside the report for file descriptions.

**Important:** Entries marked `Observed` are limited to supplied screenshots or code inspection. `User-reported` results are not independently reproduced. Entries marked `Needs verification` must not be presented as passed tests. Update the report after running those cases and documenting actual results.

This phase is a static prototype: JavaScript-driven behaviors and persistent backend data are intentionally out of scope.
